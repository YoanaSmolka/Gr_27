Вот ваша компактная и практичная шпаргалка по всем командам Git и терминала, которые мы сегодня настроили и разобрали. Сохраните её себе в заметки, чтобы она всегда была под рукой!
------------------------------
## 1. Настройка Терминала на Mac 🖥️
Если вам когда-нибудь понадобится отредактировать внешний вид командной строки или починить опечатку:

* nano ~/.zshrc — открыть файл конфигурации терминала.
* source ~/.zshrc — применить изменения в терминале прямо сейчас (без перезапуска приложения).

Внутри редактора Nano:

* Ctrl + O затем Enter — сохранить изменения.
* Ctrl + X — выйти из редактора.

------------------------------
## 2. Работа со ссылками репозиториев (Remote) 🔗
Если Git выдает ошибку, что репозиторий не найден, или адрес указан неверно:

* git remote -v — проверить, к какому адресу привязан ваш текущий проект.
* git remote set-url origin https://github.com — изменить адрес репозитория на правильный.
* git remote remove origin — полностью удалить привязку к удаленному серверу.
* git remote add origin ССЫЛКА — привязать проект к GitHub с нуля.

------------------------------
## 3. Первая и последующие отправки кода (Push) 🚀

* git push --set-upstream origin main (или коротко git push -u origin main) — отправить ветку на GitHub в самый первый раз и связать её с сервером.
* git push — отправлять код во все последующие разы (короткая команда, когда ветки уже связаны).

------------------------------
## 4. Авторизация и Безопасность 🔒

* Вместо обычного пароля от GitHub при запросе в терминале всегда нужно вставлять Personal Access Token (токен доступа), который начинается на ghp_....
* git config --global credential.helper osxkeychain — команда, которая заставляет Mac запомнить ваш токен в «Связи ключей», чтобы не вводить его каждый раз.

------------------------------
## 5. Полезные команды для работы с файлами 📁

* cd .. — выйти из текущей папки на один уровень вверх.
* cd ~ — быстро перейти в домашнюю (главную) папку пользователя.
* rm имя_файла.json.swp — удалить обычный файл.
* rm -rf .git — полностью удалить скрытую историю Git из папки (используйте осторожно, только если случайно создали Git не в той папке, например, в корне компьютера).
